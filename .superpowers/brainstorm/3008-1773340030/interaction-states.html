Interaction State Machine

How mouse events flow through region selection, edge-resize, and deselect

STATE: idle (no selection)
STATE: dragging (new selection)
STATE: selected (finalized)
STATE: edge resize (right edge grabbed)

Phase 2 — Drag to DAW

When a region is finalized: click + drag anywhere inside the selection → writes a temp WAV slice → initiates NSDraggingSession → drop onto Pro Tools / Finder / any app.
